## Overview

**“Did You Notice?”** is an interactive, story-led learning module designed for beginner programmers. Instead of abstract syntax, learners discover programming logic through an engaging narrative involving Emperor Akbar, Birbal, and two palace workers.

Through this story, learners follow a foundational decision-making paradigm:
> **CHECK → DECIDE → ACT**

After observing the pattern in the story and in everyday real-world examples, learners seamlessly transition to how Python models decisions with `if` and `else` statements, followed by an applied scenario (College Event ID Verification).
