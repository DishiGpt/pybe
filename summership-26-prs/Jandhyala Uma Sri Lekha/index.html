WHAT ABOUT A COMPUTER?

Birbal could look at the situation and decide what to do.

But a computer needs us to describe the decision clearly.

How could we tell a computer to follow the same rule?

Python Intro — Step 2 of 7

Recreating Birbal's Rule

Birbal's Rule
Was the task completed before sunset?
YES ↓ "Give the reward"
NO ↓ "No reward"
DID YOU NOTICE?

This is the same pattern we just discovered:

CHECK ➔ DECIDE ➔ ACT

Python has a way to express this pattern.

Python Intro — Step 3 of 7

Introducing "if"

if finished_before_sunset:
    print("Give the reward")
if tells Python: Do this only when this is true.
Try Changing the Value:
finished_before_sunset = True
if finished_before_sunset:
print("Give the reward")
Python Output: "Give the reward"
Python Intro — Step 4 of 7

Introducing "else"

But what should happen when the condition is not true?

if finished_before_sunset:
    print("Give the reward")
else:
    print("No reward")
else tells Python: what to do when the condition isn't true.
